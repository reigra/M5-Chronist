In diesem Archiv sind die Scripte die  gebraucht werden um die Regeldateien zu erstellen. Einfach das ZIP irgendwohin entpacken, z.B. nach Dokumente\MagusNG

Zum erstellen die create-rules-files.cmd ausführen. 
Wenn alles funktioniert, werden die EVA Files runtergeladen und daraus die Rule-Files erstellt. 
Wenn Python nicht gefunden wird, Python installieren oder über den Windows Store beziehen. Anschließend das Script nochmal starten.

Am Ende sollten drei eva_*.json im Verzeichnis rules sein.

Jetzt https://magusng-pwa-823c6f.gitlab.io/ aufrufen. Es wird ein Chromebasierter Browser benötigt. Firefox geht leider nicht.
Man kann die App installieren (oben rechts in der Adresszeile). Dann kann man sie direkt aus dem Startmenü / Desktop ausführen.
Die App läuft komplett im Browser und funktioniert auch offline.
Alle Daten werden lokal auf dem eigenen Rechner gespeichert. Es wird nichts auf irgendwelchen Servern gespeichert.

Unter "Regeln verwalten" die drei json-Files laden.

Oben unter "+ Neuer Charakter" kannst du jetzt einen Charakter eingeben.

Falls du einen Fehler findest oder was fehlt, kannst du unter https://gitlab.com/silbaer/magusng-pwa/-/work_items?sort=created_date&state=opened&first_page_size=20 oben rechts ein neues Issue erstellen.
